\begin{itemize}
    \item \textbf{Affichage des données} : Permet de visualiser les données provenant du moniteur.
    \item \textbf{Capture d'images} : La caméra capture les images du moniteur de signes vitaux.
    \item \textbf{Reconnaissance des valeurs} : L'OCR analyse les images capturées pour extraire les valeurs à partir du texte.
    \item \textbf{Génération des alertes} : Crée des alertes basées sur les valeurs extraites par l'OCR.
    \item \textbf{Livraison des notifications} : Envoie les alertes générées au système de notification.
\end{itemize}
