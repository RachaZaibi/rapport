L’architecture garantit :
\begin{itemize}
    \item \textbf{Modularité} : Séparation claire des composants (collecte, traitement, notification).
    \item \textbf{Réactivité} : Alertes en temps réel pour une réponse rapide aux situations critiques.
    \item \textbf{Interopérabilité} : Compatibilité avec les technologies OCR et les standards d’échange de données médicales.
    \item \textbf{Flexibilité} : Option de déploiement sur serveur local ou cloud pour une adaptation aux besoins de l’hôpital.
\end{itemize}
