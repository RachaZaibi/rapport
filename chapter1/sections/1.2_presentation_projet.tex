Le projet, intitulé Développement d'un système de collecte de données en temps réel et de gestion des alertes pour les machines en salle de réveil , s'inscrit dans une démarche d'innovation technologique au service des pratiques médicales. Il vise à transformer la surveillance post-opératoire par une approche intégrée combinant \textbf{IoT}, \textbf{traitement de données} et \textbf{notifications en temps réel}.

\subsection{Objectifs Principaux}
\begin{itemize}
    \item \textbf{Acquisition des données} : 
    \begin{itemize}
        \item Collecte automatisée des paramètres vitaux (fréquence cardiaque, pression artérielle, SpO$_2$) 
        % \item Compatibilité multi-source : OCR pour les machines anciennes (solution \textit{retrofit}) + API pour les moniteurs Mindray
    \end{itemize}
    
    \item \textbf{Gestion des alertes} :
    \begin{itemize}
        \item Notifications basées sur des seuils critiques
        \item Configurations dynamiques des seuils d'alerte
    \end{itemize}
    
    \item \textbf{Notifications en temps réel} :
    \begin{itemize}
        \item Push notifications via FCM
    \end{itemize}
    
    % \item \textbf{Optimisation des processus} :
    % \begin{itemize}
    %     \item Réduction de 70\% des vérifications manuelles (cible)
    %     \item Délai d'alerte < 15 secondes (objectif temps-réel)
    % \end{itemize}
\end{itemize}
